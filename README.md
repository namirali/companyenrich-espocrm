# CompanyEnrich for EspoCRM

An installable CompanyEnrich extension, based on the official [EspoCRM extension template](https://github.com/espocrm/ext-template).

[CompanyEnrich](https://companyenrich.com) provides APIs for company enrichment, business and professional-profile search, similar-company discovery, and workforce research.

This repository is the standalone extension project; it is not part of EspoCRM core. Implementation and installation instructions are provided in the integration pull request.
